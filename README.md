# 台積電(2330.TW)股票資料分析教學案例

用 Python 走一遍完整的股票資料分析流程，以台積電（2330.TW）近 2 年真實股價資料為練習對象。

## 流程

1. **下載資料** — 用 `yfinance` 抓取歷史股價
2. **資料清理** — 檢查缺值、異常值
3. **敘述統計** — 平均、標準差、區間報酬率
4. **技術指標** — 移動平均線（MA20/MA60）、RSI(14)、布林通道（20,2）、MACD(12,26,9)、年化波動度
5. **視覺化** — 價格走勢＋均線＋布林通道、成交量、RSI、MACD 四合一圖表
6. **簡單回測** — 均線交叉策略 vs. 買進持有（教學示範，未計手續費與稅金）

## 使用方式

```bash
pip install yfinance pandas numpy matplotlib
python stock_analysis_2330.py
```

執行後會產生股價分析圖表（PNG）與整理後的資料表（CSV）。
